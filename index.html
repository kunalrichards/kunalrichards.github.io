I don't just use AI tools — I build them and integrate them into every QA workflow.

What is Vibe Coding?

Coined by Andrej Karpathy in 2025, Vibe Coding means describing what you want in plain English and letting AI write the code. I use Claude Code CLI, GitHub Copilot, and Cursor IDE every day to ship production QA tools in hours, not weeks.

In 2025–2026, I built 4 production tools this way. My team uses them daily for bug reporting, test case generation, and coverage analysis — all fully automated and AI-powered.
